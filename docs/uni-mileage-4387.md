# UNI-V OS mileage sync (RUDI v4.387)

Existing owner car only (Changan UNI-V 2023). No second car identity, GPS locations or route uploads. Owner creates a six-digit 10-minute pairing code in Car / Mileage. The same installation can retry a lost pairing response. A second device cannot claim that code. Recreating or revoking the connection invalidates the old access token. Pairing attempts are capped at eight per minute for this single car; tokens contain 256 bits and only their hash is persisted.

The head unit remains the source of absolute mileage and original daily buckets. Immutable revisioned snapshots prevent duplicate addition and out-of-order overwrite, including manual downward correction. Current day/week/month/year are projected from the source buckets using the head unit timezone and identical calendar boundaries. Old mileage history is retained as data but no longer rendered, and old estimates are replaced by four source period tiles. Existing normal car card and other fields are preserved. While linked, manual mileage editing in RUDI is hidden and rejected server-side. Disconnect keeps the latest total in the existing car state.

Android 1.2.17 includes the 1.2.16 safeguard: automatic GPS accumulation stays suspended pending real head-unit diagnostics after physical recurrence of stationary drift. This release does not claim that drift's underlying cause is fixed. Existing period totals may include earlier false kilometers; no historical data is silently deleted. Synchronization is optional, posts at most every five minutes while the app or user-enabled trip service runs, and retries from persisted state after a failed request or restart. Manual correction / service completion can send immediately. Local state is never overwritten by a server response.

Validation: eight new/retirement backend tests pass; owner/partner browser car UI and four imported periods pass; native mocked HTTPS pairing, unavailable server, retry, acknowledgement, unchanged-state throttling, correction and disconnect pass. Android trip, ledger, persistence, default suspension and UI layout tests pass. Physical head-unit pairing / TLS could not be tested here.
