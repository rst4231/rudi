# Общие заметки
Общая страница Рустама и Дианы рядом с играми. Оба могут создавать, редактировать и удалять записи. Заголовок, текст, до трёх сжатых изображений; HTTP(S)-ссылки отображаются словом «ссылка». Светлая и тёмная темы.

1. Общий авторизованный API на существующем хранилище RUDI: отдельные записи и общий индекс; защита от конкурентной перезаписи и блокировка мутаций.
2. Страница списка и редактор: сохранение по кнопке, подтверждение удаления, предупреждение о несохранённых правках, ошибки без потери текста. Обновление при открытии и возвращении в приложение.
3. Подключение через существующий API router, домашнюю панель, build asset list и service worker.
4. Проверки чтения и редактирования обоими пользователями, конфликтов, вложений, небезопасных ссылок, удаления и отказа в доступе. Один деплой только после подтверждения.

## Уточнения пользователя
Переключатель Личные / Общие. Личные записи доступны только авторизованному владельцу, общие редактируют и удаляют оба. Личные заметки сохраняют существующие ключи и историю. Выбор записи для главной сохраняется отдельно для каждого пользователя на сервере. На главной отображается содержимое выбранной заметки, а не копия.
