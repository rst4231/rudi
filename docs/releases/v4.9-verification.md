# Проверка v4.9

Добавлен блок Дела над БАДами в профиле партнёра. Считаются оставшиеся невыполненные дела на сегодня и завтра по Москве: личные и совместные с этим ответственным. Дела без времени входят только во Всего. Названия и идентификаторы задач не возвращаются в ответе API. Интерфейс оформлен компактной таблицей: строки Сегодня и Завтра, столбцы Утром, Днём, Вечером и Всего.

Сборка `npm run build` прошла. 45 проверок пакета прошли: новый API и интерфейс обоих профилей, авторизация, отсутствие личных полей, повторяющиеся задачи, границы периодов и московской даты, общие задачи, штрафы за просрочку и версия приложения, переход месяца и года, повторное использование запросов на оба дня и контраст цветов светлой и тёмной тем. Проверка интерфейса выполнена в JSDOM; браузерная визуальная проверка не выполнялась из-за отсутствия Chromium.

Общий `npm test` остановился на существующих ошибках mood-picker-flow. Дополнительная проверка календаря и ресурсов выявила ещё три существующие ошибки. Все восемь ниже воспроизведены отдельно на неизменённом исходном коммите v4.8 c03f6487:

- `dialog reuses weather dimensions and contains no emoji rendering` (mood-picker-flow.test.cjs)
- `actual dialog clicks show text, retain analyzer, save final draft and restore scroll` (mood-picker-flow.test.cjs)
- `actual custom answer form saves text; analyzer and Escape never save drafts` (mood-picker-flow.test.cjs)
- `keyboard focus stays inside dialog; busy save ignores cancel and duplicate clicks` (mood-picker-flow.test.cjs)
- `Diana hides category and shares the existing delete button only for saved tasks` (diana-personal-calendar.test.cjs)
- `Diana timeline drag uses the shared gesture, saves time, and suppresses the release click` (diana-personal-calendar.test.cjs)
- `read-only sections prefer live API online and use snapshots only as fallback` (web-assets.test.cjs)

Дополнительно проверен реальный путь событий Apple: iCloud ICS → личный календарь Дианы → счётчики сегодня и завтра. События без времени, повторы и отмены обработаны; личные названия и URL не попадают в ответ. Пять проверок подписки Apple прошли; существующая ошибка `external iCloud events cannot enter the private editor or drag gesture` из diana-calendar-subscription.test.cjs отдельно воспроизведена на v4.8.
