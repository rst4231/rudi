# RUDI v4.390

Shared expenses save after a 900 ms input pause or field blur, with one serialized write at a time. Drafts are captured synchronously in actor-scoped local storage before the network request. An offline/error draft remains available after reopening and retries on reconnect or foreground. Each captured draft retains its original month. Late responses never replace active input values. The manual save button is removed.

The editor says Коммунальные за прошлый месяц. The total breakdown says ЖКУ за прошлый месяц. Comparison text uses прошлого месяца instead of a named month.

Each actor receives one derived Жилье obligation for their own 40/60 share of rent, utilities and extra shared items. Amounts are resolved from the exact shared month in the expense list, calendar, Home bills and reminders; an unknown month's housing amount is not carried over. The payment does not create a ledger expense or debit a wallet. It cannot be removed, renamed, deactivated or have its amount changed through plan writes. Each actor can set a recurring day of month (default 1) and independently mark months paid. Existing personal obligations are retained. The generated row is not stored among ordinary obligations, preventing duplicates on repeated saves.
