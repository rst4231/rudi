# Проверка v4.10

В профиле Рустама для Дианы под строками Сегодня и Завтра отображается сохранённое в календаре место работы: Дома или Коворкинг. Источник прежний, rudi-calendar-workplace-v1:rustam; настройки не зашиты в код. Пустая отметка скрывает подпись. Права изменения места работы не менялись.

Сведения приходят вместе с существующим ответом partner-task-counts, отдельного запроса браузера нет. Они передаются только авторизованной Диане. Ошибка чтения места работы не скрывает задачи и не подставляет Дома по умолчанию. Счётчики и интеграция Apple сохранены.

Из личной страницы Рустама убрана карточка Финансы. Её отдельный запрос self-finance-summary больше не выполняется. Основной раздел финансов и собственная страница Дианы сохранены; это проверено открытием реальных страниц в JSDOM для обоих аккаунтов.

Сборка npm run build прошла. 51 проверка пакета прошли: данные по двум датам, изменение и удаление отметок, ограничение для нужного профиля, ошибки хранилища, таблица и контраст обеих тем, календарь, звёзды и версия. Интерфейс проверен в JSDOM, визуальная проверка в браузере не выполнялась из-за отсутствия Chromium.

Общий npm test остановился на четырёх существующих ошибках mood-picker-flow.test.cjs, ранее воспроизведённых на неизменённой v4.8 (см. v4.9-verification.md):

- dialog reuses weather dimensions and contains no emoji rendering
- actual dialog clicks show text, retain analyzer, save final draft and restore scroll
- actual custom answer form saves text; analyzer and Escape never save drafts
- keyboard focus stays inside dialog; busy save ignores cancel and duplicate clicks

Блок БАДы на собственной странице Рустама перенесён сразу под Твоя неделя. Источник и обработчики отметок прежние, обновления клонируются из главной карточки без дублей. Страница Дианы сохранена. Проверено реальным открытием обоих профилей и изменением данных источника.

Пакет v4.10 готов. Production пока v4.9, публикация не запускалась.
