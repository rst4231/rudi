# Проверка v4.13

Подтверждена ошибка отступов на реальном рендере приложения v4.12. Одного gap было недостаточно: кнопка настроения растягивала строку имени до 26 px, а более специфичное правило партнёра меняло gap. JSDOM-проверка не воспроизводила итоговый каскад и размеры.

До исправления расстояние между текстовыми прямоугольниками составляло: Рустам 8,00 px, Диана 4,95 px, Лулу 1,36 px. После: Рустам 1,09 px, Диана 1,27 px, Лулу 1,36 px. Имя теперь задаёт высоту строки, а кнопка настроения позиционируется отдельно и сохраняет область 26 px. Исправлен каскад владельца и партнёра.

Добавлен браузерный регрессионный тест на полном приложении со штатными тестовыми API. Все четыре исходных сценария воспроизвели ошибку до правки. После правки прошли все 12 сценариев: оба аккаунта, обе темы, ширины 375/393/430 px. Проверены промежутки имя/статус и статус/цикл Дианы относительно Лулу с допуском 1,5 px, сохранена область кнопки настроения.

Сборка и 72 модульные проверки пакета прошли. Общий npm test останавливается на прежних ошибках mood-picker-flow.test.cjs:

- dialog reuses weather dimensions and contains no emoji rendering
- actual dialog clicks show text, retain analyzer, save final draft and restore scroll
- actual custom answer form saves text; analyzer and Escape never save drafts
- keyboard focus stays inside dialog; busy save ignores cancel and duplicate clicks

Пользователь подтвердил v4.12 на телефоне. Автообновление не является подтверждённой причиной этого случая и не менялось. Проверка выполнена Chromium на эмулированных размерах iPhone, без утверждения о запуске Safari на устройстве пользователя.
