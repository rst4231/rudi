# Проверка v4.11

Рабочий статус Рустама отображает Работаю дома или Работаю в коворкинге при сегодняшней отметке. Рабочие часы 10:00–18:00 по Москве в будни сохранены; вне работы статус Отдыхаю. Без отметки статус Работаю. Данные передаются существующим home bootstrap обоим аккаунтам, отдельного браузерного запроса нет. Отметка другой даты не применяется. Локальное несинхронизированное изменение Рустама учитывается сразу.

Имена Рустам, Диана и Лулу на главной оформлены Georgia italic с системным serif fallback. Оформление ограничено главными карточками. Внешние шрифты не загружаются, цвета обеих тем сохранены. Применение стиля проверено через JSDOM для обоих режимов. Визуальная браузерная проверка не выполнена из-за отсутствия Chromium.

Сборка npm run build и 70 проверок пакета прошли: статусы обоих аккаунтов, рабочее время и выходные, даты, локальные отметки, фактический рендер статуса, home bootstrap, задачи, прогулки, штрафы, присутствие, версия, перенос БАДов и удаление финансов из профиля Рустама.

Общий npm test останавливается на прежних ошибках mood-picker-flow.test.cjs, воспроизведённых ранее на v4.8:

- dialog reuses weather dimensions and contains no emoji rendering

- keyboard focus stays inside dialog; busy save ignores cancel and duplicate clicks
