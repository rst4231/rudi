# RUDI v1.8.6: ускорение запуска

Основа: production v1.8.4, commit `204f9e62411c70a6c9990e2e7ccf4ab2c2eeb6a7`; ветка main при начале работы `422d6cc`.

## Что изменено

- Настройки запрашиваются параллельно с авторизацией. Свежий локальный кэш действует 5 минут; сохранённые настройки доступны сразу. Устаревшие настройки обновляются в фоне для следующего открытия. При первом запуске ожидание ограничено 1200 мс, запрос отменяется через 4 секунды, используется существующая резервная конфигурация.
- Сборка создаёт JS/CSS с SHA-256 в имени. Только эти файлы получают годовой immutable-кэш. HTML остаётся no-store, поэтому новые версии получают свежие ссылки автоматически. Повторная сборка неизменённых файлов сохраняет ссылки.
- Скрипты загружаются параллельно из head с defer; порядок Telegram SDK, основного приложения, умного дома и машины сохранён.
- Обычный первый pageshow больше не запускает повторно пакет обновлений. Возврат через bfcache и обработчик visibilitychange продолжают обновлять данные.
- Три запроса следующего месяца перенесены с главной страницы на переход в календарь.
- Настройки авторизации, резервного копирования, данных пользователей и backend endpoints не изменены.
