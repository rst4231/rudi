# RUDI v4.19: КПТ по трём неделям

Первая неделя соответствует скриншоту 3: событие как факт, эмоции и сила 0–10, интерпретация и вера 0–100. Вторая соответствует скриншоту 2: письменная проверка интерпретации, связь с эмоцией и поведением, более объективный взгляд. Третья соответствует скриншоту 1: ту же схему проговаривать сразу после ситуации устно; запись необязательна и может быть короткой.

Изменение применяется к текущему дню текущего цикла. Не запускать новый цикл, не менять ключи хранения, идентификаторы, календарь или даты старта. Старые поля поддерживать при отложенных правках и показывать отдельно. Смешанные записи целиком сохранять при конфликтах и экспорте. Старые AI-разборы сохранить; новый анализ запускать только по запросу и учитывать метод недели.

Проверки: все CBT-тесты, интерфейсные сценарии с текущим циклом версии 1, сохранёнными/черновыми записями, старой офлайн-очередью и копией старых тем. Отдельно смешанный набор 17 полей, исторические анализы и сборка. Настоящие пользовательские записи в тестах не используются. Изменения публиковать одним деплоем после подтверждения пользователя.
