# RUDI versioning

Правило версий для следующих релизов:

- Крупное изменение приложения: увеличить основную версию на 1.
- Мелкое изменение: увеличить дробную версию.
- Несколько мелких изменений, объединённых в один production deploy, получают одну новую minor-версию.
- Диагностика без production deploy версию не меняет.
- Текущий релиз: `v4.54`. Следующее мелкое обновление: `v4.55`.

Источник истины текущей версии: `rudi-version.json.current` и `VERSION`.
