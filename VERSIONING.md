# RUDI versioning

Правило версий для следующих релизов:

- Крупное изменение приложения: увеличить основную версию на 1. Пример: `v2 → v3`, `v3 → v4`.
- Мелкое изменение: увеличить дробную версию. Пример: `v3 → v3.1 → v3.2`.
- Несколько мелких изменений, объединённых в один production deploy, получают одну новую minor-версию.
- Диагностика без production deploy версию не меняет.
- Текущий крупный релиз: `v3`.

Источник истины текущей версии: `rudi-version.json.current` и `VERSION`. Сборка синхронизирует web-assets с этой версией.
